# 常见陷阱

> 本文件收录**不包含在主流程规则里、需特别提醒**的坑。
> 凡是 SKILL.md 正文已明确写过的规则（文字门禁、规格、布局、人物生动性、默认 G 风格、BGM/渲染门禁等），此处不再重复——遇到问题先回正文查。
> 按问题域分组，便于按现象定位。

## 一、生图类

1. **人物变脸**：灰度层和彩色层用了不同的图（或去色后几何漂移）→ 灰度图必须由彩色原图直接去色得到，两图同场景同构图（见 1.5.3）。
2. **AI 线稿与彩色图严重错位 / 填色后画面变深变脏**（注：当前默认圆形擦头方案用灰度图、不用 multiply，这两条主要影响旧的线稿扫入方案）：
   - **错位（高频，AI 线稿特有）**：AI 图生图去色即便以彩色图为唯一参考、提示词明确要求"几何零漂移"，**实测仍会重画轮廓**。一个 7 场故事实测覆盖率 ±2px 仅 42-96%（多数 51-62%），50% 透明叠加肉眼可见人物轮廓、五官、手部明显错位，叠加动画时上色模糊/重影。**不要相信"轻微漂移不易察觉"——轮廓阶段错位很刺眼**。**解法：默认用灰度图**（`magick color.png -grayscale Rec709Luma lineart.png`），几何天然 100% 对齐、零丢失。只有纯黑线稿风格（A 涂色页）或能逐张解决漂移时才用 AI 线稿，且必须做 50% 叠加检查 + ±2px ≥ 90%。
   - **画面变脏（旧线稿扫入方案特有）**：旧方案 Layer 2 误用 `mix-blend-mode: multiply`，灰度图或带灰阶的 AI 线稿相乘会把彩色整体压暗。**当前默认圆形擦头方案不使用 multiply，无此问题**。若仍用旧扫入方案，解法是 Layer 2 改用 `opacity: 1 - colorProgress` 在填色阶段淡出。
3. **生图失败 / 风格混用**：AI 生成的图不合格 → 每场最多重试 3 次，换种子/微调提示词；仍不行则换风格。**全片必须锁定同一种风格**（A/B/C/D/F/G/G2/G3），不同场用不同风格是硬错。
4. **风格选了偏写实的（不像手绘）**：本 skill 是"手绘遮罩动画"，整体调性是手绘感。选了写实钢笔淡彩、写实水彩这类偏插画/写实的风格，生成的图会像商业插画而非手绘，与灰度→彩色擦除显色动画违和。优先选 A/B/D/G/G3（手绘线稿属性最强），C/F 谨慎用，**不要用写实水彩类风格**。
5. **用英文提示词被审核拦截**：生图提示词写成英文 → 多数生图工具对英文提示词审核更严，容易整段被拦、被改写或被误判违规，出图不稳定。**解法**：**全部提示词用中文**；生图工具的结构化 API 字段名（`aspectRatio`、`quality` 等）保留英文，那不是提示词、不影响审核。
6. **填色浓度或留白错误**：颜色浓度明显偏离约 70% 或纯白留白少于 60% → 调整颜色可见度和背景覆盖，保持低饱和蜡笔纹理与大面积纯白留白；不再使用"彩色面积必须约 1/3"的机械限制。
7. **同一角色跨场换色**：填色时只提供无颜色的场景线稿，模型会在每场随机猜测衣服和道具颜色 → 场景线稿作为第一参考锁几何，同时附带已确认角色全家福作为第二参考锁配色，并在每场提示词中重复同一份固定配色表；生成后逐场对照角色主色。
8. **并行生图文件名冲突**：并行生图（最多 5 张）时，若输出文件名不唯一会导致互相覆盖 → 每场提前指定唯一文件名（如 `01-rain-door.png`、`02-...`），单批 ≤5 张，超过分批发起；并行仅能在**参考图门禁和逐场文字门禁都通过后**才可启动。

## 二、擦头动画类（圆形擦头方案）

9. **擦头出现横向条纹空隙（铁律）**：擦头缩小后行间距没同步缩小，相邻行擦痕不重叠，出现"一行有颜色一行没颜色"的条纹 → **行间距必须 ≈ 擦头半径 × 1.3**。改小 `ERASER_RADIUS` 时同步重算行间距，不要只改半径。
10. **擦痕过于规整**：路径采样点和半径完全等距等大，擦痕像工程扫描线而非手绘 → 必须给每个采样点的**位置和半径**加固定种子随机抖动（半径抖动 ±20px 左右），让擦痕边缘参差自然。注意用固定种子，否则逐帧闪烁。
11. **擦头羽化太硬或太软**：羽化用纯硬边圆 → 边缘锯齿；羽化过度 → 显色区模糊发灰 → 用 `radialGradient`（45% 实心 → 100% 透明）做柔和但不过度的羽化。
12. **遮罩漏色**：mask 未覆盖区域提前透出下层 → 圆形擦头方案中，确保 mask 底色为 black、只把已走过的擦头圆画成 white；采样点间距 ≤ 半径，避免漏点。

## 三、合成 / BGM 类

13. **BGM 音量过小**：默认 `volume={0.2}` 会让纯音乐视频声音太轻 → 纯 BGM 视频（无人声）用 `volume={1}` 满音量；只有叠加人声配音时才降到 0.1–0.2 做避让。
14. **文字扫入时人物头部提前露彩**：Layer 3 统一固定裁剪顶部 33%，不会根据单张图片文字位置动态调整。若用户反馈文字或留白布局不理想，再按需修改生图提示词重生图片，不要修改遮罩高度；生图后**不要自动扫描像素强制重生**。
